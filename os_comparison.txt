[1] 핵심 특징 비교표
================================================================================
+----------------------+-------------------------+-------------------------+-------------------------+
| 항목                 | macOS                   | Windows                 | Linux                   |
+----------------------+-------------------------+-------------------------+-------------------------+
| 개발사               | Apple Inc.              | Microsoft               | 커뮤니티/리누스 토르발즈|
| 최초 출시            | 2001년 (Mac OS X)       | 1985년 (Windows 1.0)    | 1991년 (Linux 커널)     |
| 라이선스             | 상용(독점) / 무상 업데이트| 상용(독점)              | 오픈소스 (GPL 등)        |
| 기반 커널            | XNU (Darwin, Unix 계열) | NT 커널                 | Linux 모놀리식 커널      |
| 계열                 | Unix 계열               | 독자 계열 (POSIX 부분)   | Unix-like               |
| 파일 시스템(기본)    | APFS                    | NTFS                    | ext4 / Btrfs / XFS      |
| 기본 셸              | zsh                     | PowerShell / cmd        | bash (배포판마다 다름)   |
| 패키지 관리          | Homebrew / App Store    | winget / MS Store       | apt / dnf / pacman 등    |
| 하드웨어 호환성      | Apple 하드웨어 전용     | 매우 광범위             | 매우 광범위 (드라이버 편차) |
| 지원 CPU 아키텍처    | Apple Silicon(ARM), x86_64 | x86_64, ARM64        | x86_64, ARM, RISC-V 등   |
| GUI                  | Aqua                    | Fluent Design (WinUI)   | GNOME / KDE / XFCE 등    |
| 게임 지원            | 제한적 (개선 중)        | 최상 (DirectX)          | 중간 (Proton/Wine으로 개선)|
| 개발자 도구          | Xcode, Unix 툴 기본     | Visual Studio, WSL      | GCC/Clang, 풍부한 CLI    |
| 보안 모델            | Gatekeeper, SIP, 샌드박스| Defender, SmartScreen   | 권한 기반, SELinux/AppArmor|
| 업데이트 방식        | 자동/누적               | 자동/누적(Patch Tuesday)| 배포판별 (rolling/LTS)   |
| 가격(개인)           | 하드웨어 포함, OS 무료  | 약 $139 (Home)          | 무료                    |
| 주 사용층            | 크리에이터, 개발자      | 일반 사용자, 기업, 게이머| 개발자, 서버, 임베디드   |
| 서버 시장 점유율     | 매우 낮음               | 낮음~중간               | 압도적 (약 80% 이상)     |
| 데스크톱 점유율(2026)| 약 15%                  | 약 71%                  | 약 4%                    |
+----------------------+-------------------------+-------------------------+-------------------------+


[2] 장단점 요약표
================================================================================
+---------+---------------------------------+---------------------------------+
| OS      | 장점                            | 단점                            |
+---------+---------------------------------+---------------------------------+
| macOS   | - 하드/소프트 통합성 우수       | - Apple 기기에 종속             |
|         | - Unix 기반, 개발 환경 우수     | - 고가                          |
|         | - 안정성/디자인 완성도 높음     | - 게임/특정 상용 SW 부족        |
|         | - 배터리/전원 관리 효율         | - 커스터마이징 제한             |
+---------+---------------------------------+---------------------------------+
| Windows | - 광범위한 SW/HW 호환성         | - 라이선스 비용                 |
|         | - 게임 지원 최상 (DirectX)      | - 백그라운드 리소스 사용 큼     |
|         | - 기업/오피스 표준              | - 강제 업데이트 이슈            |
|         | - 주변기기 드라이버 풍부        | - 광고/텔레메트리 부담          |
+---------+---------------------------------+---------------------------------+
| Linux   | - 무료, 오픈소스                | - 상용 SW/게임 지원 부족        |
|         | - 서버/개발/임베디드 최강       | - 하드웨어 드라이버 편차        |
|         | - 커스터마이징 자유             | - 초보자 학습곡선 존재          |
|         | - 리소스 사용 효율적            | - 통합된 공식 지원 창구 부재    |
+---------+---------------------------------+---------------------------------+
